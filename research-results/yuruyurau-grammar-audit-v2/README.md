# Yuruyurau grammar audit v2

Status: **triggered** on 2026-08-29 after a new user-supplied example plus a current-stream corpus review.

This audit studies reusable mathematical mechanisms, not an artist style and not exact formulas. No current route is changed by this document.

## Why this audit is now warranted

Earlier Yuruyurau examples were visually strong but still plausibly mapped to the existing route repertoire. The new example and a current stream sample expose a repeated construction that is materially different from the native topology of the five routes.

The repeated mechanism is provisionally named **index-multiplexed latent geometry**:

1. one dense sample index carries more than one coordinate role at once;
2. a slow longitudinal coordinate is combined with one or more fast oscillatory coordinates derived from the same index;
3. discrete residue/parity channels (`i % m`, parity/bit tests, or an equivalent categorical branch) create multiple phase-linked submanifolds without an explicit organ hierarchy;
4. latent coordinates are collapsed through a nonlinear radius-like quantity such as a Euclidean magnitude and then reused in several downstream roles;
5. that same latent radius participates in phase, amplitude, deformation strength, and time coupling rather than serving only as a geometric coordinate;
6. multiplicative cross-coupling creates coherent macrostructure and fine structure from the same few variables;
7. some members use reciprocal or near-singular terms as controlled structure generators rather than treating them only as invalid geometry.

This is not equivalent to “organic point art.” The hypothesis is specifically about **sampling topology + latent-variable reuse + discrete branching**.

## Comparison with current routes

### recurrence

Native topology: one smooth longitudinal coordinate with symmetric side samples. It has an `i % 2` implementation detail for side placement, but branch identity does not enter the core phase/radius equations. It therefore cannot natively express multiple phase-linked manifolds generated by residue classes of the primary sample index.

### filament

Native topology: one smooth spine plus normal-offset sides. Again, parity controls whether side samples are emitted; it is not a latent branch coordinate. Cross-frequency terms exist but remain functions of one normalized smooth parameter.

### orbit

Native topology: one smooth closed angular manifold with continuous radial modulation. Its contract deliberately rejects large sampling discontinuities. This is almost the opposite of residue-class phase branching.

### sheet

Native topology: an explicit regular two-dimensional `(u,v)` lattice with smooth fold/ripple/twist fields. It can imitate some silhouettes, but the second dimension is explicit and smooth rather than emergent from fast/slow reuse of one dense index. It has no categorical branch coordinate and no nonlinear latent radius reused across topology and motion.

### family

Native topology: explicit root sheet + a discrete hierarchy of organs. It can create multiple appendages, but branch count and anchors are semantic structure, not residue classes of a common sampler. It therefore reaches multiplicity by a different grammar.

## Decision

The previous “do we need more Yuruyurau examples?” condition is now satisfied **for study**, but not yet for adding a production representation.

The current evidence supports a real grammar-gap hypothesis:

> The five-route repertoire is biased toward smooth explicit manifolds and explicit organ hierarchies. It lacks a native mechanism where a single dense index is multiplexed into slow, fast, and categorical coordinates, with a nonlinear latent radius reused to couple shape and motion.

That is enough to justify a targeted capacity experiment. It is not enough to merge a sixth route merely because the references are aesthetically strong.

## Next experiment: multiplex-capacity-v1

Build a neutral experimental grammar from the mechanisms above without porting any source formula or attempting to imitate a specific Yuruyurau work.

Candidate primitive:

- dense scalar sampler `s`;
- slow coordinate `u = f_slow(s)`;
- fast coordinate `v = trig(f_fast * s + phase)`;
- categorical coordinate `b = index mod m` with small `m`;
- latent radius `r = nonlinearity(hypot(v, u_offset))`;
- output coordinates using independently parameterized couplings of `(u, v, b, r, t)`;
- optional bounded reciprocal term with an explicit safety floor;
- no fixed “animal”, wing, jellyfish, or organ semantics.

### Capacity question

Does this primitive expose structural phenotypes that the current five routes fail to recover under equal search budget, while still producing meaningful internal diversity rather than one narrow Yuruyurau-like family?

### Evidence discipline

1. Start on already-consumed seeds only.
2. Use route-stratified equal budget.
3. Define challenge targets from neutral mechanism combinations, not copied reference formulas.
4. Measure geometry/descriptor coverage and recovery, not description length.
5. Include ablations for each proposed mechanism:
   - remove categorical branch;
   - replace index multiplexing with explicit regular 2-D grid;
   - stop latent-radius reuse after coordinate construction;
   - remove reciprocal term.
6. A candidate sixth route advances only if the full mechanism materially beats both:
   - best current-route recovery;
   - its own simplified ablations.
7. Then test on fresh seeds before any route admission.
8. Artistic review remains independent and blind.

## Non-goals

- cloning Yuruyurau;
- fitting the supplied example pixel-for-pixel;
- importing exact formulas from public posts;
- treating engagement metrics as aesthetic evidence;
- changing outer route authority;
- retuning the confirmed repertoire allocator around this corpus.
