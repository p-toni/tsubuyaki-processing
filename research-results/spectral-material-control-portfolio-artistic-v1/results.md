## What this establishes

For the confirmed intrinsic-1D route class, adding the frozen K=2 / amplitude-16 spectral material-control operator to an equal-budget native search creates a generated **portfolio surface that is artistically preferred** by the independent reviewer on fresh seeds.

This is stronger than the prior mechanical evidence alone. The representation/operator now has:

1. fresh route-class mechanical confirmation;
2. equal-budget portfolio confirmation;
3. fresh integrated runtime replay;
4. fresh blinded human artistic support at the generated-portfolio authority surface.

## What it does not establish

This result does **not** validate the current deterministic temporal proxy selector.

The immediately preceding champion-level review (`spectral-material-control-artistic-v1`) produced 12 equivalent judgments because both native and mixed runtime arms selected the exact unchanged shared start in every block. That was a selector/delivery-layer failure, not a failure of the spectral intervention.

The present review deliberately exposed three target-blind generated hard-valid challengers from each complete trajectory using only deterministic generation-order quantiles. No structural score, semantic target, proxy vote, model judge, novelty score, human preference, or post-hoc oracle selected the presented candidates.

## Reviewer signal

The reviewer explicitly reported:

> Ratings favor the side in each set demonstrating structural variation and dynamic morphologic exploration across seeds (rows 1–3), over the side containing redundant/identical copies.

After unblinding, that criterion selected the mixed arm in all 12 blocks.

This qualitative evidence should be treated as a hypothesis generator for the next selector/delivery experiment, not as permission to tune on this consumed review set.

## Architectural implication

Separate **search capacity** from **delivery authority**.

The mixed spectral operator is now supported as a discovery/search portfolio component for intrinsic-1D routes. The unresolved problem is how to reduce that richer archive without collapsing it back to an unchanged incumbent.

The next experiment should therefore target the selector/delivery layer on entirely fresh evidence. It should preserve route validity and identity contracts while testing whether a target-blind variation-aware reduction can retain the useful structural/dynamic diversity that the human review identified.

Do not retune the spectral operator on these consumed ratings.
