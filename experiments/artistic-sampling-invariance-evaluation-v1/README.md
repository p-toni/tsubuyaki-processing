# Artistic sampling-invariance evaluation v1

Independent human-evidence layer after `bandlimited-k2` passed fresh structural-capacity confirmation and the exact `12 discovery -> 8 top-one geodesic exploitation` policy passed fresh objective-search confirmation.

This experiment does **not** re-test structural recovery and does **not** use the confirmed search objective to choose what the reviewer sees. It isolates a different question:

> Does the new sample-invariant spectral representation expose a static visual-form grammar that is artistically competitive with the current five-route repertoire under a blind, equal-exemplar comparison?

## Evidence boundary

The earlier judge calibration established that same-model artistic judgments cannot grant promotion. Accordingly:

- generation contains no same-model or deterministic aesthetic selector;
- hard mathematical validity may exclude invalid samples;
- presentation is mechanically symmetric;
- representation, route, seed, and A/B mapping are sealed from the reviewer;
- only strong human / independent-model evidence may support artistic admission;
- if the reviewer cannot make a strong call, the block is `unreviewable` rather than forced.

This is a **static form-grammar** admission test. It does not evaluate temporal behavior because the current `bandlimited-k2` representation is intentionally static. A positive result does not by itself authorize a production route or a temporal mechanism extension.

## Frozen review-only population

Four review-only master seeds were checked absent from repository code/history before branch creation:

```text
98009, 98011, 98017, 98041
```

Every seed is paired once with every incumbent route:

```text
recurrence, orbit, family, sheet, filament
```

Total: **20 blind review blocks**.

Excluded smoke seed: `9001`, one block per incumbent route. Smoke output cannot count as artistic evidence.

## Frozen sampling contract

For each representation side in a block, generate exactly **six first-hard-valid independent phenotypes** from representation-native priors using a review-only RNG namespace.

No phenotype score, target distance, brief semantics, model judgment, structural niche, or prior experiment outcome may select among valid samples.

### Incumbent route side

- use the route's native genome prior;
- use the route's native hard-validity checker;
- accept the first six hard-valid independent candidates;
- render only canonical time `t=90`.

### Spectral side

- fixed `bandlimited-k2` coefficient prior from the confirmed representation;
- unchanged spectral hard-validity contract;
- accept the first six hard-valid independent coefficient vectors;
- render the zero-set geometry.

The confirmed `12/8` optimizer is deliberately **not** invoked here. Capacity/navigability and artistic grammar are separate evidence layers; using target recovery to curate one side would confound representation with objective search.

## Shared neutral renderer

Cross-representation presentation uses one frozen neutral renderer so route-specific opacity/material does not reveal identity or dominate form comparison:

```text
400 x 400
background = 9
foreground = 255
point alpha = 48
canonical static frame only
no contrast stretching
no intensity normalization after rendering
```

For incumbent routes, native geometry points at `t=90` are passed through this renderer. For the spectral route, rasterized zero-set support points are passed through the same renderer.

Thus the reviewer judges **geometry/form grammar**, not route-specific material styling.

## Allowed judgment

Per block:

- `A>B`
- `B>A`
- `equivalent`
- `unreviewable`

Question:

> Which side contains the stronger static mathematical-form grammar worth keeping / developing?

Use `unreviewable` whenever confidence is low. Do not infer route identity or reward similarity to any named artist/reference.

## Frozen artistic-admission gate

After all 20 human judgments are fixed and the sealed key is decoded, score:

- spectral preferred: `+1`
- incumbent preferred: `-1`
- equivalent: `0`
- unreviewable: `0` for net preference and excluded from reviewable count

Classify **`ARTISTIC_ADMISSION_SUPPORT`** iff all hold:

1. at least **15 / 20** blocks are reviewable;
2. total spectral-vs-incumbent net preference is **> 0**;
3. every leave-one-incumbent-route-out spectral net preference is **> 0**.

Otherwise classify **`ARTISTIC_ADMISSION_NOT_SUPPORTED`**.

Route-specific nets, decisive win counts, and exact sign-test values are diagnostics only and cannot override the frozen gate.

## Hard invariants

Fail closed unless:

1. every review block has six hard-valid spectral phenotypes and six hard-valid incumbent phenotypes;
2. no phenotype is selected by an artistic or target score;
3. canonical time is exactly `90` for incumbent geometry;
4. both sides use the exact same neutral renderer and alpha;
5. all 12 rendered phenotype fingerprints inside a block are recorded in the sealed key;
6. reviewer-facing sheet contains no route, seed, representation, candidate id, or policy identity;
7. the key and review sheet are uploaded as separate artifacts;
8. all five smoke blocks pass before any review block executes;
9. all 20 review blocks complete before a review bundle is considered valid;
10. frozen confirmed spectral representation/source blobs are unchanged.

## Interpretation

Positive support means only:

> for this independent human reviewer and current five-route repertoire, the confirmed sample-invariant spectral representation contributes a static form grammar strong enough to justify continued integration research.

It does **not** establish universal aesthetic superiority, route pruning, temporal quality, or production admission.

A negative result does not invalidate confirmed structural capacity or objective navigability. It means those mechanical gains have not translated into independent artistic utility under this static neutral-renderer contract.
