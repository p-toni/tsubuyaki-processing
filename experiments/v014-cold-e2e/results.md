## Temporal-horizon finding

The main new finding is not a change to *where* description pressure belongs. v0.14's promotion boundary worked.

The finding is about the quality of the falsification gate:

> **compression preflight and exact verification must inspect the same meaningful temporal horizon.**

A short preflight window can create a false sense of survival for recurrent systems whose compact phenotype changes more dramatically later.

This does not imply universal frame numbers such as `30/90/150`. The correct rule is to choose representative times that span the relevant motion cycle / behavioral horizon for the candidate, and use that same coverage for preflight and final verification.

## Production interpretation

Supported:

- keep description length out of generation and artistic ranking;
- preserve a non-deployable artistic winner as a valid discovery;
- adaptively preflight visually ranked candidates;
- fallback only when a higher-ranked candidate fails;
- golf only the first passing deployment finalist;
- final exact verification remains mandatory.

Potential narrow refinement:

```text
preflight temporal coverage
must match final survival coverage
```

Do not hard-code frame indices or add a temporal scalar score.

## Limitations

- one evaluator;
- one fresh brief per route;
- 12 challengers per route;
- representative frames rather than continuous video;
- recurrence and sheet only;
- compact forms hand-authored semantically rather than produced by an automatic compressor.
