# Spectral material-control runtime replay v1

## Question

Does the confirmed intrinsic-1D native+spectral operator portfolio survive integration into the actual adaptive search runtime under a fixed search budget, while leaving native-only behavior replay-compatible?

This is a deployment/mechanical gate only. It grants no artistic authority.

## Search shape

Each route is run separately with exactly one valid start basin. This prevents route/frontier pruning from changing the number of generated challengers between arms while preserving the real adaptive incumbent-challenge loop.

Routes:

- `recurrence`
- `orbit`
- `filament`

Per route/arm:

- starts: 1;
- explore: 4 challengers;
- round A: 4 challengers;
- refine: 12 challengers;
- total challenger attempts: 20.

Native-only therefore spends 20 native attempts. Mixed search spends exactly 10 native + 10 spectral attempts: each local batch uses a native prefix followed by its spectral half.

Both arms reset from the same search seed and therefore have the same initial start candidate. Generation and adaptive selection are target-blind. Structural targets are constructed/scored only after both full trajectories have finished.

The selector is the existing `DeterministicTemporalSelector` in both arms. It drives the runtime trajectory but has no authority in the result; the outcome metric is the frozen sparse-geometry structural recovery metric applied post hoc to the full valid candidate archive at t=90.

## Cell outcome

For each master seed × route × target:

- `nativeRecovery` = best t=90 recovery among all hard-valid candidates generated by native-only runtime, including the shared start;
- `mixedRecovery` = same for mixed runtime;
- `delta = mixedRecovery - nativeRecovery`.

There are `16 × 3 × 15 = 720` paired cells.

Master-seed inference uses the mean of all 45 route×target deltas for each seed. Route inference uses each route's mean across 15 targets for each master seed.

## Preregistered decision gate

`SPECTRAL_MATERIAL_CONTROL_RUNTIME_PROMISING` requires **all**:

1. complete hard-invariant 720-cell rectangle;
2. exact 20-vs-20 challenger budget for every route/seed;
3. exact 10 native + 10 spectral mixed allocation for every route/seed;
4. overall master-seed mean delta >= `+0.003`;
5. one-sided 95% lower confidence bound over 16 master-seed means > 0;
6. all three route mean deltas > 0;
7. each route separately has a positive one-sided 95% lower bound over its 16 master-seed means;
8. every leave-one-target-family-out mean delta > 0;
9. fraction of cells with delta > `+0.005` exceeds fraction with delta < `-0.005`;
10. spectral hard-validity >= 0.95 pooled and >= 0.90 for every route;
11. no target family contributes > 50% of total positive advantage.

One-sided t critical for df=15 is frozen as `1.7530503556925547`.

If any gate fails, decision is `SPECTRAL_MATERIAL_CONTROL_RUNTIME_NOT_PROMISING` and this exact runtime schedule is not tuned on these seeds.

## Decision

The fixed 50/50 native+spectral portfolio survives integration into the actual adaptive runtime. The implementation may remain as an opt-in mechanical search path for intrinsic-1D grammars.

This closes the mechanical chain:

```text
representation capacity
→ local spectral operator
→ fresh intrinsic-1D confirmation
→ equal-budget mixed portfolio
→ exact runtime implementation equivalence
→ fresh end-to-end adaptive runtime replication
```

The next unresolved question is artistic, not mechanical: under blind same-grammar comparison, does mixed search produce mathematical forms a human reviewer prefers to the native-only search output?

## Authority boundary
