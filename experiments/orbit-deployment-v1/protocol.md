# Orbit deployment/compression survival v1 — frozen protocol

## Question

Can visually selected orbit phenotypes survive the actual #つぶやきProcessing deployment medium as complete executable posts <=280 raw code points and <=280 X-weighted characters?

## Development vs confirmation

One taxonomy target (`closed-pulse`, seed `616842`) was used only to discover a fixed semantic compression grammar. It is excluded from confirmatory claims.

The confirmatory holdout is the six orbit elites previously selected blind in `orbit-five-arm-v1`:

- `closed-pulse`: seeds `365728`, `837514`, `275892`;
- `wounded-halo`: seeds `365728`, `837514`, `275892`.

These expanded phenotypes and their genomes were frozen before this compression experiment.

## Fixed compact grammar

For every holdout genome, generate one tweet candidate from the same code template. The compiler may quantize numeric constants but may not change structure after seeing a holdout render.

Preserved roles:

- periodic angular path / closed 1-D topology;
- persistent central void;
- low-frequency lobe term;
- higher-frequency ripple term with independent phase/time;
- global asymmetry term;
- localized periodic dent;
- angular warp;
- elliptical projection;
- sparse doubled path as a compact surrogate for subtle side structure.

Intentionally dropped for compression:

- independent Cartesian fold/fold2 terms;
- width-phase modulation of side structure;
- separate x-scale (radius absorbs most scale; y-scale remains explicit);
- exact sample count.

## Temporal horizon

Use the same representative orbit horizon `t = 30, 90, 150`, which spans enough phase change to expose lobe/ripple drift and dent/warp coherence in these phenotypes.

## Exact deployment checks

For every generated post:

1. exact raw code-point count <=280;
2. exact X-weighted length <=280 using the repository checker semantics;
3. JavaScript parse/runtime through 150 draw calls with p5-compatible stubs;
4. zero non-finite point calls;
5. exact compact mathematical period retains closure, central aperture and angular coverage;
6. render the exact compact formula at t=30/90/150.

## Blinded compression-survival judgment

For each holdout block, compare expanded target vs compact output with A/B order randomized and target identity hidden.

This is not a preference contest. Decide:

- `pass` — defining orbit identity/relationships clearly survive;
- `borderline` — route identity survives but a defining high-leverage relationship is materially weakened;
- `fail` — compact output loses the selected orbit identity/topology/material or temporal behavior.

## Acceptance

Orbit compression viability is supported if:

- all 6 exact posts pass length/runtime/finite checks;
- at least 5/6 pass artistic compression survival;
- no more than 1/6 is `fail`;
- all 6 retain closed-path/aperture hard topology in the compact cause.

Anything weaker remains a research-only representation with deployment risk. No production SKILL change from this experiment alone.
