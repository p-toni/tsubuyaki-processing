# Orbit deployment / compression-survival v1

## Result

A fixed semantic compiler was developed on one excluded orbit target, then frozen and applied without structural retuning to six previously selected orbit elites from `orbit-five-arm-v1`.

```text
exact posts under <=280: 6/6
150-frame JS runtime:     6/6
non-finite point calls:   0 / 18,000,000
closed topology valid:    6/6
blinded phenotype survival: 6/6 pass
```

Exact post ranges:

- raw Unicode code points: **257–262**;
- X-weighted length: **261–266**.

The compiler preserves a compact orbit cause rather than hand-golfing each image independently:

```text
periodic angular path
+ low-frequency lobes
+ high-frequency ripple / independent phase
+ global asymmetry
+ localized periodic dent
+ angular warp
+ elliptical projection
+ sparse doubled path
```

It intentionally drops the expanded representation's independent Cartesian fold terms and width-phase modulation. Across the holdout, those losses did not remove the selected orbit identity over the `t=30/90/150` horizon.

## Interpretation

Orbit is not merely a research-only expressive representation: its defining relationships can survive the actual #つぶやきProcessing deployment medium with meaningful budget headroom.

This does **not** by itself justify a production routing change. Remaining major gates are independent-judge replication and representation-allocation policy.

## Experimental hygiene

- the development target (`closed-pulse`, taxonomy seed `616842`) is excluded from claims;
- all six holdout targets were selected in an earlier experiment before this compiler existed;
- the compiler structure was frozen before holdout rendering;
- exact code length, JavaScript execution, finite coordinates, topology and artistic survival were all checked separately;
- character count never influenced the earlier artistic selection of these targets.
