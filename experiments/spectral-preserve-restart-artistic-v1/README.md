## Bias-control corrections

This review deliberately closes presentation loopholes discovered during #112.

1. **No resampling for visible difference.** Cross-arm identical portfolios are valid `equivalent` evidence.
2. **No rejection for within-side visual redundancy.** The runtime really may deliver visually redundant forms; hiding that would condition away an artistic defect. Exactly three delivered candidate objects must render, but they need not be visually distinct.
3. **Balanced A/B position.** Within every route, treatment appears as A in exactly two blocks and B in exactly two blocks.
4. **Hidden block-order randomization.** Route/seed pairs are deterministically shuffled from the blind salt before assignment to R01-R12, so blocks are not grouped by seed or route.
5. **Display-order randomization.** The three delivered candidates on each displayed side are independently permuted from block ID + side label. Runtime shortlist order is therefore not exposed as a visual rank cue.
6. **No identity metadata in the reviewer artifact.** Route, seed, arm identity, candidate IDs, genomes, operator histories, structural scores, duplicate diagnostics, and the A/B key remain sealed.

None of these rules selects or rejects a block based on which arm looks better.
