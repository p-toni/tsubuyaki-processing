# Orbit taxonomy v1 — frozen protocol

## Primary question

Can the existing recurrence representation reach the closed-aperture niche with a small brief-preserving structural extension, or does doing so effectively require a separate representation?

## Fixed design

Seeds: `616842`, `216139`, `980564`.

Briefs:

- `closed-pulse` — sparse closed recurrent loop around a persistent empty center;
- `returning-knot` — self-returning recurrent line closed around a persistent empty center;
- `living-knot` — historical broad recurrence control;
- `open-knot` — open recurrent near-closure control.

Four matched starts per structural condition. Candidate genomes for recurrence-derived conditions are shared; only projection/closure changes. Identity is blinded during artistic selection.

## Structural ladder

- unchanged recurrence;
- Cartesian endpoint closure;
- periodic-domain reparameterization;
- polar remap with unchanged recurrence genes;
- full orbit representation.

No new recurrence genes are allowed in the first four conditions.

## Follow-up validity falsification

If a recurrence-derived polar candidate is artistically competitive but fails closed-orbit validity, repair closure using transformations that add no genes and preserve the existing recurrence numeric mutation grammar.

Two repairs are permitted in sequence:

1. distributed seam correction;
2. local smooth bridge preserving the original contour as closely as possible.

For each repair, measure fresh-start and local-mutation validity under both the existing recurrence contract and closed-orbit contract, then rerun blinded artistic comparisons.

## Decision rule

Subtype is supported only if a recurrence-derived condition:

- passes closed-orbit hard validity robustly;
- remains artistically competitive with full orbit on closed briefs;
- does not displace normal recurrence on open controls;
- uses the existing recurrence genome/mutation grammar rather than importing the orbit gene set.

If valid minimal repairs consistently lose to full orbit, retain orbit as a separate top-level research representation.
