# Reviewer instructions

Review `R01`–`R12` without trying to infer which side is the experimental treatment.

For each block, judge only:

> Which side contains the stronger portfolio of mathematical forms worth keeping or developing further?

Allowed judgments:

- `A>B`
- `B>A`
- `equivalent`
- `unreviewable`

Each side contains three target-blind max-dispersion forms shown at `t=30`, `t=90`, and `t=150`.

If A and B are visually identical, rate the block `equivalent`. Exact cross-side identity is valid evidence; it is not a presentation error and should not be used to infer which arm is which.

Do not use candidate identity, route, seed, structural benchmark scores, or implementation details. Those are intentionally absent from the reviewer package.
