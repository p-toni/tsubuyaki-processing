# Route-screen hybrid safety v1

## Question

Does the evidenced two-exemplar route screen behave safely on deliberately hybrid briefs, and does it reveal a gap in the current five mathematical representation families?

## Frozen setup

- reused the fresh v19 archive to isolate review semantics from candidate generation;
- two exemplars per representation;
- three matched temporal frames per exemplar;
- fresh sealed A–E mapping;
- four deliberately hybrid briefs;
- reviewer was allowed `keep / drop / defer` and an explicit `none fit` response.

Sealed mapping after review:

```text
A orbit
B sheet
C recurrence
D filament
E family
```

## Human response

Toni supplied positive keeps only:

```text
ragged aperture   E → family
braided veil      B → sheet
breathing knot    C → recurrence
colonial skin     E → family
```

No response was marked low confidence and no brief received `none fit`.

The reviewer also explicitly reported fatigue with repeated rating tasks at this point in the experimental sequence.

## Interpretation

This is **not** a complete keep/drop screen. Omitted groups are not retroactively interpreted as authoritative drops.

Therefore v20 does not justify hard narrowing. Instead it exposes a useful low-burden review mode:

```text
explicit strong keep
→ focus extra search budget

unmentioned / uncertain route
→ unresolved; keep alive at minimum depth

explicit strong drop
→ only then hard-prune
```

This is consistent with the existing fail-closed authority boundary and avoids turning reviewer fatigue or terse responses into false exclusion evidence.

## Representation-vocabulary signal

The pre-registered vocabulary-gap trigger was:
- explicit `none fit`, or
- repeated inability to identify any plausible grammar among the current routes.

Neither happened. All four hybrid briefs had a plausible positive grammar under the current representation set.

So additional yuruyurau math/art examples are **not yet required for representation-family discovery**. The trigger remains active for a later stage when the current grammars repeatedly fail to express human-preferred visual structure.

## Architectural consequence

Positive human evidence should be useful even when a reviewer does not exhaustively label all routes. In an incomplete screen, unresolved routes retain nonzero budget, while explicit keeps may receive the remaining extra budget. Hard elimination continues to require an explicit strong human/independent `drop`.
