# Route-screen probe depth v1

## Question

Can a blinded human route screen use **two independent exemplars per mathematical representation** instead of four without changing the selected visual grammar?

The purpose is compute economics, not aesthetic winner selection. Route identities remain sealed until both review passes are persisted.

## v18 — nested reduction on the existing grammar archive

Three previously reviewed clear briefs were shown again using only the first two exemplars of each anonymous grammar under a fresh sealed label mapping.

Human route decisions at two exemplars matched the earlier four-exemplar decisions exactly:

```text
split orchard      family      == family
open turbulence    recurrence  == recurrence
crowned aperture   family      == family

preservation: 3/3
```

This was development evidence only; a fresh archive was required before changing the runtime default.

## v19 — fresh frozen confirmation

Fresh setup:
- five representations: recurrence, orbit, family, sheet, filament;
- fresh route-specific RNG archive;
- four independent first-valid starts per representation;
- all 20 candidates valid on first attempt;
- temporal horizon `(30, 90, 150)`;
- five fresh briefs;
- two-exemplar and four-exemplar A–E mappings shuffled independently and sealed before review;
- route identities remained sealed until both passes were complete.

Human decisions after unsealing:

| brief | two exemplars | four exemplars | preserved |
|---|---|---|---|
| loose whirl | filament | filament | yes |
| ruptured bloom | family | family | yes |
| pleated membrane | sheet | sheet | yes |
| drawn wire | recurrence | recurrence | yes |
| dented halo | orbit | orbit | yes |

Primary criterion: **5/5 exact route identity preservation — PASS**.

No two-exemplar judgment was marked low confidence.

## Combined result

```text
v18 nested preservation   3/3
v19 fresh preservation    5/5
combined                   8/8
```

This supports changing the route-screen runtime default from four probes per route to **two probes per route** for clear route screening.

One probe per route remains unevidenced and must not become the default from this result.

## Budget implication

For five routes and target depth 10 starts/route:

```text
unscreened breadth             50 starts
2 probes/route + keep 1        18 starts   (64% less)
2 probes/route + keep 2        26 starts   (48% less)
2 probes/route + keep 3        34 starts   (32% less)
```

Generation count only; reviewer/model inference cost remains separate.

## Limitations

Small n, one human reviewer, clear briefs, and the current five-representation vocabulary. This calibrates probe depth for the research prototype; it does not establish universal artistic-route accuracy.
