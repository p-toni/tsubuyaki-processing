# End-to-end evidence authority v1

## Purpose

Join the route-level evidence boundary from the screened-search work with the phenotype-oriented fine-grained promotion boundary.

The resulting research contract is:

```text
brief
→ semantic prior (advisory)
→ two-probe exposure for every mathematical representation
→ route screen
   ├─ explicit strong keep → focus extra budget
   ├─ omitted/defer        → keep alive at minimum depth
   └─ explicit strong drop → may hard-prune
→ exact probe replay
→ adaptive search
→ advisory pairwise selector may suggest challenger ordering
→ strong human/independent phenotype evidence is required for elite replacement
```

Hard mathematical validity remains authoritative independently of artistic evidence.

## Why explicit mode

The legacy adaptive runtime remains useful for research replay and existing experiments. Evidence-authoritative candidate promotion is therefore opt-in rather than silently replacing historical behavior.

When enabled:
- candidate evidence directories are decoded by phenotype fingerprint;
- unresolved pairs can be exported to a v3 review queue;
- deterministic/same-model advisory judgments are visible but cannot promote;
- A/B order reversal is safe because evidence resolves the winning phenotype fingerprint rather than a panel label.

If candidate evidence/review options are supplied without enabling evidence-authoritative mode, the run fails instead of silently ignoring them.

## Iterative replay

Fine-grained authoritative search is intentionally iterative:

```text
run 1 → queue unresolved phenotype pairs; no unsupported promotions
review → persist human/independent evidence
replay → evidenced promotions may change the elite
        → new downstream pairs can become reachable and are queued
repeat until frontier is sufficiently resolved or deliberately deferred
```

Every replay remains seeded and route-probe prefixes are revalidated before adaptive search begins.

## Reviewer-burden correction

The hybrid v20 calibration produced one positive keep per brief and explicit reviewer fatigue. Omitted routes are therefore not interpreted as drops.

Positive-only human route evidence can focus extra compute while unresolved routes remain alive at the minimum. Hard route exclusion still requires an explicit strong drop.

This lets terse human input remain useful without turning incomplete review into false certainty.

## Yuruyurau / representation-vocabulary trigger

The current five representation families still produced a plausible positive grammar for every v20 hybrid brief; no `none fit` response occurred.

Additional yuruyurau math/art examples become directly useful when either:
1. a brief repeatedly produces `none fit` across the current five grammars, or
2. human-preferred examples exhibit a structural visual grammar that cannot be generated by the current recurrence / orbit / family / sheet / filament contracts.

Until that trigger, the main experimental bottleneck remains evidence-efficient search rather than representation-family discovery.
