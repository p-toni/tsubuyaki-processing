# Morphology route activation pair — results

## Executive result

The paired internal pilot supports both sides of the routing contract:

```text
explicit differentiated anatomy + local editing
-> morphology-first is useful

animal-like appearance without local anatomy/editing
-> morphology-first is unnecessary
```

This is **not** an independent cold-agent replication. The same evaluator constructed and judged the candidates.

## Brief A — positive morphology control

Requested:

- differentiated root mass;
- visible central split/cavity;
- attached repeated organ family;
- one root-local control;
- one coherent family control;
- one global motion control.

Chosen route:

```text
morphology-first explicit anatomy
+ semantic controllability
```

The strongest candidate was **M9**.

It uses:

```text
root mass field
-> central split/cavity
-> parent-relative repeated organ anchors
-> one shared organ generator across 8 siblings
```

### Semantic control evidence

At the same representative time:

```text
root-width control: +25%
observed root width: +25%
median local organ-shape spill: 0%
max local organ-shape spill: 0%
```

The anchors move with the parent because attachment is parent-relative, but the local organ law is unchanged.

Family control:

```text
requested organ length: +25%
median sibling length change: +25%
directional agreement: 1.0
relative MAD: 0.0
siblings: 8
```

This is the concrete value morphology provides for this brief: semantic locality and coherent repeated-family editing.

Temporal diagnostics across t=0/12/24/36 remained stable:

```text
occupancy ~= 6.0%
bbox width ~= 67.4-67.6%
bbox height ~= 56.2-56.5%
```

## Brief B — negative morphology control

Requested:

- one continuous compact mathematical generator;
- animal-like / ray-like appearance allowed;
- bilateral spread + trailing impression;
- no named anatomical editing.

The first one-field batch produced coherent folded sheets but was not a strong enough adversary: resisting morphology was too easy because the forms did not read clearly enough as animals.

That was treated as a **representation failure before search**, not as a reason to change route.

The repaired continuous mapping produced a much stronger ray/manta-like family while keeping:

```text
independently authored anatomical parts = 0
morphology graph = none
```

The strongest candidate was **R11**.

Its apparent anatomy comes from one mapping:

```text
(u,v)
-> continuous width field
-> bilateral spread
-> central extension from the same field
-> fold/curl/time deformation
-> (x,y)
```

No wing, tail, head or body generator exists separately.

Across t=0/12/24/36 R11 retained the animal-like identity:

```text
occupancy ~= 10.0-10.7%
bbox width ~= 82.4-83.2%
bbox height ~= 59.1-60.0%
```

So animal-like appearance alone is not evidence that morphology-first should activate.

## What this supports

1. **Route by requested semantics, not silhouette.**
   - explicit local anatomy/editing benefits from hierarchy;
   - emergent animal-like appearance can remain math-first.

2. **Representation repair should happen before route escalation.**
   - the first negative batch was too generic;
   - strengthening the continuous field solved the visual brief without adding parts.

3. **Morphology has a concrete job.**
   - semantic locality;
   - parent-relative attachment;
   - repeated-family coherence.

It should not be treated as a universal complexity generator.

## What this does not establish

This run does not prove:

- that a fresh evaluator will choose the correct route without author contamination;
- that morphology-first is always superior for explicit creature briefs;
- that one-field math-first forms always compress better;
- that the positive candidate is tweet-viable.

Character count was excluded from route choice and artistic selection by protocol.

## Next replication target

The high-value follow-up remains an **external cold pair**:

```text

+
negative animal-like math-first control
```

using a different evaluator identity and preserving evaluator/version metadata.

If that external pair agrees with this internal result, morphology route coverage becomes substantially stronger.
