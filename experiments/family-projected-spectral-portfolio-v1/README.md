# Family projected-spectral portfolio v1

## Question

Does the mechanically supported family-law projected spectral operator from #131 remain useful when it replaces half of an otherwise native family challenger budget, under the same equal-compute portfolio design that previously validated spectral material control on the intrinsic-1D class?

This is a mechanical integration experiment only. It does not change runtime behavior, grant artistic authority, or authorize `sheet` spectral control.

## Prior evidence

#131 established on fresh `762xxx` evidence that:

- generic K=2 / amplitude-16 spectral deformation strongly improves structural recovery on `family` but fails hard validity because it breaks sibling-scale coherence;
- projecting each warped sibling around its warped anchor so its native anchor→tip length is preserved eliminates that exact failure (`240/240` valid, zero sibling-law failures);
- the projected operator retained `98.84%` of generic spectral added recovery and beat native mutation by `+0.02088` on fresh disjoint targets.

Operator-level usefulness is not sufficient to assume equal-budget search/portfolio usefulness. This experiment tests that next layer directly.


Total:

```text

```

The candidate's three native attempts per start are the exact first three baseline native challengers, phenotype-for-phenotype. Therefore the two arms share the same starts and an exact six-candidate native prefix; only the final six evaluation slots differ.

Projected-spectral attempts use the exact #131 treatment:

- K=2;
- amplitude 16;
- generic Hamiltonian pointwise warp;
- same native family genome as the shared start;
- each warped sibling is rescaled around its warped anchor so its anchor→tip length equals its native length;
- no retries, no adaptive amplitude, no checker-threshold tuning.

All invalid attempts consume budget.

## Consequence
