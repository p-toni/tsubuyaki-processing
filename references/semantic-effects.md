# Semantic Effect Descriptors

Semantic validation separates three questions:

1. **scope correctness** — did change stay inside the region/subtree it was allowed to affect?
2. **effect correctness** — did the intended observable move in the intended direction?
3. **family coherence** — when one generator creates repeated siblings, did the intended effect occur across those instances rather than only in aggregate?

A control can have perfect scope locality and still be semantically wrong.

## Effect sources

### `mask`

Use baseline/variant diagnostic masks. Best for simple region geometry:

- `area`
- `width`
- `height`
- `centroidX`
- `centroidY`

Example:

```json
"finSpan": {
  "region":"fins",
  "scope":"region",
  "effect":{"source":"mask","metric":"width","direction":"increase","minRelativeChange":0.05}
}
```

### `image`

Measure appearance inside each state's region support:

- `visibleFraction`
- `meanContrast`

Useful for surface/detail controls.

### `math-family`

Use this when a repeated family is generated by one mathematical rule and aggregate image geometry can hide uneven sibling behavior.

The readable system exposes a pure probe sample:

```js
{
  family:'arms',
  instance:3,
  x:...,
  y:...,
  latent:{radial:...,axial:...,phase:...}
}
```

The control descriptor names the latent field and per-instance aggregation:

```json
"armLength": {
  "region":"arms",
  "scope":"region",
  "effect":{
    "source":"math-family",
    "family":"arms",
    "field":"radial",
    "metric":"max",
    "direction":"increase",
    "variantFactor":1.2,
    "minMedianRelativeChange":0.05,
    "minAgreement":0.8,
    "maxRelativeMAD":0.15
  }
}
```

Supported per-instance math metrics:

- `max`
- `min`
- `range`
- `mean`
- `rms`
- `absMax`

The `field` may be `x`, `y`, a top-level sample field, or a latent field such as `radial` / `latent.radial`.

Run:

```sh
node scripts/check-family-math.mjs \
  probe.mjs morphology-contract.json armLength --factor=1.2
```

The checker reports each instance's relative response plus:

- median relative change;
- directional agreement across siblings;
- median absolute deviation (MAD) of responses;
- min/max sibling response.

This distinguishes:

```text
[+9%, +7%, +9%, +8%, +8%]
```

from:

```text
[+4%, -3%, +77%, +66%, -6%]
```

even if both increase the family-wide bounding box.

## Direction

- `increase`
- `decrease`
- `any`

For `mask`/`image`, `minRelativeChange` rejects negligible effects.

For `math-family`, prefer:

- `minMedianRelativeChange` — family-level effect strength;
- `minAgreement` — fraction of siblings moving in the intended direction;
- optional `maxRelativeMAD` — reject extreme sibling disagreement when coherent family behavior is intended.

Thresholds are project-calibrated diagnostics, not universal laws.

## Validation stack

For explicitly controllable repeated morphology, use the strongest available source of truth:

```text
math-family probe   → did the generator change each sibling correctly?
raster scope        → did the resulting change leak into forbidden anatomy?
image/mask effect   → does the simple visible observable agree?
visual judgment     → is the phenotype actually compelling?
```

Do not force `math-family` onto a system that has no meaningful repeated instance identity.

## Chaotic / recurrence controls

A tiny perturbation to a chaotic kernel can cause legitimate global divergence. Do not judge a Lorenz-like recurrence parameter by sibling agreement or local raster spill.

Instead distinguish:

- recurrence parameters — global dynamical semantics;
- projection controls — alter visualization without changing the trajectory;
- residue/family controls — can often use `math-family` validation.

When predictable local editing is desired, prefer controls in the projection/family layer rather than the chaotic kernel itself.

## Limits

These validators are falsification tools, not aesthetic judges.

A width increase can still look bad. A mathematically coherent family can still be visually boring. A chaotic system can be artistically excellent while deliberately violating local-control assumptions.

Prefer descriptors only where the intended mathematical or visual effect can be stated clearly.
