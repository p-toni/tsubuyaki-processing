# v0.6 Evaluation Matrix

Use the same cold-agent protocol across all classes: load the skill fresh, choose the smallest route, generate readable source, run only relevant checks, golf, and verify the final post.

v0.6 adds two questions before explicit morphology:

1. **Can the apparent organism emerge directly from a compact mathematical kernel?**
2. **If one generator creates repeated siblings, can semantic validation inspect those instances in latent space rather than only their aggregate raster?**

## 1. Repeated harmonic / parametric family — math-first should activate

Prompt shape:

> Create an original five- or six-member organic family from one shared mathematical generator. Each sibling should feel related but phase-shifted. Expose one control that lengthens the family coherently.

Expected route:

- `math-first-generators.md` loaded;
- one latent body/generator, not literal per-sibling anatomy;
- family identity derived from modulo/parity/phase class;
- pure probe exposes stable `family`, `instance`, and meaningful latent fields;
- family control uses `effect.source="math-family"`;
- per-instance response, median, directional agreement and MAD reported;
- raster scope/effect checks may supplement but do not replace math validation.

Required adversary:

Construct a variant whose **aggregate family extent increases** while several siblings shrink or move in the wrong direction.

Expected result:

- aggregate mask width may pass;
- math-family agreement/median should fail or degrade materially.

This is the key v0.6 regression test.

## 2. Recurrence-driven emergent form — math-first dynamics should activate

Prompt shape:

> Create an original recurrence/attractor whose nonlinear projection reads like an organism, but do not explicitly construct named body parts.

Expected route:

- recurrence kernel identified separately from projection;
- state variables / integration law explained in the readable mathematical plan;
- projection/family/deformation controls distinguished from kernel parameters;
- no morphology graph unless explicit editing needs it;
- no local-family expectation applied to a chaotic kernel parameter;
- visual QA + tweet verification remain required.

Failure signals:

- recurrence is treated as literal 3D coordinates only;
- agent forces crown/wing/tail anatomy onto an already coherent dynamical system;
- chaotic divergence is mislabeled as scope leakage.

## 3. Explicit compound creature — morphology + semantic validation should activate

Prompt shape:

> Create a creature with a differentiated root mass, an attached repeated organ family, a cavity or split, and named controls affecting different anatomical levels.

Expected route:

- morphology contract required;
- reusable organ-family generators;
- parent-relative attachment;
- dual-state region masks;
- `math-family` effect preferred when repeated instances have a meaningful latent field;
- mask/image effects used for simple visible observables;
- state-aware survival features for expanded→golfed compression.

Required semantic cases:

```text
correct place + correct effect
correct place + wrong effect
correct effect + wrong place
```

For repeated families also include:

```text
aggregate effect passes + sibling coherence fails
```

## 4. 1D axial filament — legitimate 1D path

Prompt shape:

> Create a long translucent larval ribbon with one axial spine and traveling contraction waves. Keep it visibly filamentary.

Expected route:

- intentional 1D manifold;
- no forced 2D conversion because of occupancy heuristics;
- math-first family/morphology tools only if genuinely needed;
- low occupancy acceptable by intent;
- authenticity judged by folding, hierarchy and motion.

## 5. Abstract dense sheet — base workflow remains sufficient

Prompt shape:

> Create a dense abstract folded membrane with cavities and slow internal phase drift. It should feel organic but not creature-like.

Expected route:

- flattened 2D default;
- shared latent fields / density shading;
- no anatomy contract;
- no math-family probe unless repetition semantics are requested;
- visual occupancy/framing across multiple frames;
- golf only after visual stability.

# Report dimensions

For every class record:

- chosen route / kernel / topology;
- references loaded;
- iterations to viable form;
- occupancy / bbox / centroid / clipping when relevant;
- motion quality;
- raw + X-weighted length;
- qualitative authenticity.

For math-first work record:

- kernel type;
- latent fields;
- family law if any;
- deformation/projection structure;
- which controls belong to kernel vs projection/family layers.

For repeated-family controls additionally record:

- per-instance baseline/variant metric;
- median relative change;
- directional agreement;
- relative MAD;
- aggregate-raster result for comparison;
- adversarial uneven-family result.

For explicit compound work additionally record:

- dual-state scope spill;
- simple mask/image effect results;
- state-aware expanded→golfed feature survival.

# Key release criterion

v0.6 succeeds only if it can distinguish:

```text
one coherent mathematical family
from
an aggregate raster that hides contradictory sibling behavior
```

while also allowing recurrence-driven organisms to remain math-first rather than forcing every complex form through explicit anatomy.

The skill should reason from **mathematical cause → phenotype**, using image-space diagnostics as confirmation rather than as the sole semantic source of truth.
